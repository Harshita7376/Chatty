# 💬 Chatty - Android Chat Application

## 📌 About Project
Chatty is a real-time chat application developed using Android Studio. It allows users to send and receive messages instantly using Firebase as backend.

This project is built for learning Android development and Firebase integration.

## 🚀 Features
- Real-time chat messaging
- User authentication 
- Simple and clean UI
- Fast message delivery
- Firebase database integration
- Easy and smooth chat experience

## 🛠️ Tech Stack
- Android Studio
- Java
- XML (UI Design)
- Firebase Realtime Database / Firestore
- Firebase Authentication 

## 🔥 Firebase Integration
- Firebase Authentication
- Firebase Realtime Database / Firestore

## 📂 Project Structure
- app/src → Main Java source code
- res/ → Layout and UI files
- manifests/ → App configuration
- google-services.json → Firebase configuration file
